# Rehla skill workflow
1. Start with rehla-development; read AGENTS.md and relevant Cursor rules.
2. For new/changed behavior use rehla-specification and record unresolved decisions.
3. For multi-step changes use rehla-planning then rehla-executing-plans, inline only.
4. Use rehla-tdd for behavior and rehla-systematic-debugging for failures.
5. Review with rehla-code-review and verify with rehla-verification.
6. Use rehla-branch-finish for branch disposition; rehla-release only for authorized release.
7. Use rehla-skill-authoring for skill changes and test one skill at a time.
8. Engineering skills are narrow guides and do not replace the workflow.
Static artifact validation is distinct from model behavior evaluation.
